<h1>
  Installation
</h1>

```sh

git clone https://github.com/hyuse202/stu-management-api.git
cd stu-management-api

python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt
uvicorn app.main:app --reload
```
